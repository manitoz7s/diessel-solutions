# AgroManager

Protótipo educacional para o projeto de vida: uma plataforma de gestão inteligente de fazendas.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no Chrome, Edge ou Firefox.
3. Não é necessário instalar servidor ou biblioteca.

## Funcionalidades demonstrativas
- Dashboard com indicadores
- Mapa fictício da fazenda
- Localização visual de tratores
- Velocidade e velocidade média
- Combustível
- Produção e colheita
- Bate-ponto
- Manutenção
- Relatórios
- Alertas
- Design responsivo para celular

Os dados são fictícios/simulados para fins escolares.


Atualização: mapa em estilo satélite/topográfico, com quadras, estradas, lago, curvas de nível, bússola e escala visual. O GPS continua simulado para fins escolares.
